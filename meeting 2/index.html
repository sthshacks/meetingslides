Problem 01 / Easy 06 / 09
Difficulty — Easy

Even or Odd

Warm-up

Write a program with a hardcoded integer. Print whether the number is even or odd. That's it — no user input required.

Example
number = 7
output  = "odd"
7 is not divisible by 2, so it's odd.
Hint: use the modulo operator (%) Any language.

Problem 02 / Intermediate 07 / 09
Difficulty — Intermediate

Two Sum

Arrays · Hash Map

Given an array of integers nums and an integer target, return the indices of the two numbers that add up to target. Each input has exactly one solution, and you can't use the same element twice. Return the answer in any order.

Example 1
Input:  nums = [2,7,11,15], target = 9
Output: [0,1]
nums[0] + nums[1] == 9.
Example 2
Input:  nums = [3,2,4], target = 6
Output: [1,2]
Example 3
Input:  nums = [3,3], target = 6
Output: [0,1]
Constraints: 2 ≤ nums.length ≤ 104 -109 ≤ nums[i] ≤ 109 -109 ≤ target ≤ 109 Only one valid answer exists.

Problem 03 / Expert 08 / 09
Difficulty — Expert

Add Two Numbers

Linked List · Math

You're given two non-empty linked lists representing two non-negative integers. Digits are stored in reverse order, one per node. Add the two numbers and return the sum as a linked list. Assume neither number has leading zeros (except the number 0 itself).

Example 1
Input:  l1 = [2,4,3], l2 = [5,6,4]
Output: [7,0,8]
342 + 465 = 807.
Example 2
Input:  l1 = [0], l2 = [0]
Output: [0]
Example 3
Input:  l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
Output: [8,9,9,9,0,0,0,1]
Constraints: 1 ≤ nodes per list ≤ 100 0 ≤ Node.val ≤ 9 No leading zeros.
