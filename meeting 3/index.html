What is Git?

Git is a version control system. It tracks every change made to your code over time, so you can always go back to an earlier version if something breaks.

version control snapshots history

Why is Git important?

It lets you undo mistakes, work with a team without overwriting each other's code, and never lose your work. Most real software projects use it, so it's a skill worth having early.

undo mistakes team collaboration backups

Git vs. GitHub

Git is the tool that tracks versions of your code on your own computer. GitHub is a website that hosts your Git repositories online, so you can share them, back them up, and collaborate with others.

Git = the tool GitHub = the website related, not the same

Git Tutorial 06 / 14
04

Local vs. GitHub repository

A local repository lives on your own computer, inside a project folder. A GitHub repository is a copy of that history hosted online, one that teammates (or you, on another computer) can access and pull from.

local repo GitHub repo remote

Git Tutorial 07 / 14
05

What is the origin?

When you connect a local repository to GitHub, Git gives that connection a nickname: origin, by default. It's just a shortcut so you don't have to type the full GitHub URL every time. git push sends your commits to origin, and git pull pulls new changes down from it.

origin remote git push

Basic Git Commands 08 / 14
01 / START TRACKING
git init
Turns the current folder into a Git repository. You run this once, at the very start of a project.
02 / CONNECT TO GITHUB
git remote add origin <url>
Connects your local repo to a GitHub repo, so Git knows where to push your work.
03 / STAGE CHANGES
git add .
Stages every changed file in the folder, telling Git to include them in the next snapshot.
04 / SAVE A SNAPSHOT
git commit -m "message"
Saves a snapshot of everything staged, along with a short message describing what changed.

Pascal's Triangle

Arrays · Math

Given an integer numRows, return the first numRows of Pascal's triangle. In Pascal's triangle, each number is the sum of the two numbers directly above it.

Input:  numRows = 5
Output: [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
Example 2
Input:  numRows = 1
Output: [[1]]
Constraints: 1 ≤ numRows ≤ 30 Any language.
